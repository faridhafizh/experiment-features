## 2024-03-20 - Empty states in Tables
**Learning:** Tables across the app do not handle empty states well. Instead of leaving a blank table with just headers, or repeating an empty row inside the table loop, provide an empty state view with an actionable message or helpful text.
**Action:** When creating or updating tables, always include an empty state UI when there is no data.
